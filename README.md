# Валютный калькулятор

Самостоятельное одностраничное приложение в стилистике сайта Лилии Маловой. Данные загружаются из бесплатного JSON-архива cbr-xml-daily.ru, который публикует официальные курсы Банка России и разрешает запросы из браузера.

## Локальный запуск

Самый простой способ в Windows — дважды щёлкнуть файл `ОТКРЫТЬ-КАЛЬКУЛЯТОР.bat`. Он запустит локальный сервер и откроет калькулятор в браузере.

Либо откройте PowerShell в этой папке и выполните:

```powershell
python -m http.server 4173
```

Затем откройте в браузере `http://localhost:4173`.

## Проверка расчётов

```powershell
node test-core.js
```

## Размещение

Проект статический: база данных, серверный язык и платные сервисы не требуются. Для публикации достаточно разместить четыре рабочих файла (`index.html`, `styles.css`, `currency-core.js`, `app.js`) в корневой папке сайта поддомена.

Если доступ к cbr-xml-daily.ru когда-либо станет нестабильным, безопасный запасной вариант — небольшой серверный прокси на собственном VPS, который получает XML с cbr.ru, преобразует его в JSON, кеширует по дате и разрешает CORS только для `currency.malovafin.ru`.
